# Hours report

The report aggregates logged time by department, period, and work item, with a downloadable artifact when needed.

## Who can perform the operation

Cross-project hours report permission is required.

## Where to find the feature

Choose Hours report in Work management.

## How to perform the operation

Select dates and filters, start generation, and monitor the run. Download the artifact when it is ready.

## Result

The screen shows aggregated time while heavier work runs in the background without holding an HTTP request.

## Limitations and special cases

The report does not expose issue titles that the recipient cannot access. A broad range can take longer to process.
