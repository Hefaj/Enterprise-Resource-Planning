# Media library

The library lists Catalog files independently of the products that reference them.

## Who can perform the operation

Catalog dictionary read permission is required. Deleting files and generating derivatives require separate permissions shown by the interface.

## Where to find the feature

Choose Media library from the Catalog menu.

## How to perform the operation

Find an asset, select one or more rows, then choose download, generate derivatives, or delete.

## Result

Downloads save originals through the browser. Derivative generation and deletion create a task with visible progress.

## Limitations and special cases

A file referenced by a product cannot be deleted. Detach it from every product first. External addresses are not files in system storage.
