# Słownik pojęć

| Pojęcie | Znaczenie |
|---|---|
| agregat | granica spójności domenowej modyfikowana przez metody pilnujące niezmienników |
| contract | lekka warstwa frontendu eksponująca routing, menu, modale i loadery remota |
| orchestrator | serwis `data-access` łączący API, cache encji i aktualizacje realtime |
| job | trwały przebieg operacji masowej albo ciężkiej pracy w tle |
| artifact | plik będący wynikiem przebiegu lub plikiem zarządzanym przez moduł |
| remote | moduł Angular ładowany przez Native Federation |
| scope | granica modułu lub tłumaczeń określająca widoczność zależności |
| specification | opis zaakceptowanego stanu docelowego, który nie musi być jeszcze wdrożony |
