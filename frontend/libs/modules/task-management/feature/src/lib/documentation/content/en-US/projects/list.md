# Projects

The project list finds a work context and opens its configuration.

## Who can perform the operation

The list requires issue read permission. Project changes require project management permission.

## Where to find the feature

Choose Projects in Work management.

## How to perform the operation

Filter by name, code, or kind. Open a row to navigate to the project page.

## Result

You see the code, kind, lead, open issue count, and assigned schemes.

## Limitations and special cases

An archived project can be hidden by the default filter and does not accept normal new work.
