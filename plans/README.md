# Plany implementacji

Plany opisują jednorazową kolejność realizacji konkretnej zmiany. Ich cykl życia to:

1. `backlog/` — zaakceptowany zakres oczekujący na rozpoczęcie;
2. `active/` — plan aktualnie wykonywany;
3. `archive/` — zakończony plan zachowany jako historia projektu.

Po zakończeniu plan trafia do archiwum, a trwałe reguły odkryte podczas realizacji są aktualizowane
w `docs/`. Zarchiwizowany plan ani historia Git nie zastępują aktualnej dokumentacji technicznej.
