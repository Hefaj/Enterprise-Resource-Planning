# Lista zgłoszeń

Lista pozwala wyszukiwać, filtrować i wykonywać akcje na zgłoszeniach bez ładowania całego zbioru.

## Kto może wykonać operację

Odczyt wymaga uprawnienia do zgłoszeń; tworzenie i akcje masowe mają osobne uprawnienia.

## Gdzie znaleźć funkcję

W module Zarządzanie pracą wybierz Zgłoszenia.

## Jak wykonać operację

Wybierz zakres i projekt, ustaw filtry, a potem zastosuj je. Kliknij klucz zgłoszenia, aby otworzyć kartę. Zaznacz wiersze, aby użyć dostępnych akcji masowych.

## Rezultat

Tabela pokazuje serwerową stronę wyników z kolumnami dopasowanymi do profilu pól projektu.

## Ograniczenia i przypadki szczególne

„Zaznacz wszystko” obejmuje cały bieżący filtr, nie tylko widoczną stronę. Operacja masowa może zakończyć część elementów błędem.
