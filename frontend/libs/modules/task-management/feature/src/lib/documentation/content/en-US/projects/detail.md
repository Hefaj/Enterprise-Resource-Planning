# Project configuration

The project page controls its code, archive state, fields, issue types, workflow, and settings.

## Who can perform the operation

Project management permission is required; scheme configuration may require an additional permission.

## Where to find the feature

Open a project from the Projects list.

## How to perform the operation

Choose a tab, change the setting, and confirm. Review the warning before archiving. Add custom fields with a data type and stable slot assignment.

## Result

The configuration becomes the source of columns, filters, forms, and allowed transitions for the project.

## Limitations and special cases

A field with values cannot be removed safely. Changing a project code affects new issue keys but must not invalidate old links.
