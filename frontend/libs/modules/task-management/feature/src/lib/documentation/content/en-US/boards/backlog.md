# Backlog and sprints

The backlog plans issues into a sprint, starts an iteration, and resolves unfinished items when it closes.

## Who can perform the operation

Access to the board's issues is required; sprint management follows project permissions.

## Where to find the feature

Open a Scrum board and navigate to its Backlog page.

## How to perform the operation

Create a sprint, drag issues between backlog and sprint, then start it. When closing, choose how unfinished cards should be handled.

## Result

Issues preserve their rank and iteration assignment, and the board displays the active sprint.

## Limitations and special cases

The backlog exists only in a specific board context. Conflicting iterations and project rule violations are rejected.
