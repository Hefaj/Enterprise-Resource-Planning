# Troubleshooting

Common Catalog problems are caused by permissions, selection scope, or file state.

## Who can perform the operation

Every Catalog user can perform basic diagnostics; changing permissions requires an administrator.

## Where to find the feature

Check the on-screen message, toast, and job details in the header tasks panel.

## How to perform the operation

Verify the active filter and selection, refresh the list, and check whether a file is referenced by a product. For access denial, compare the requirement with the permissions article.

## Result

After removing the cause, the operation can be retried without manually clearing local application state.

## Limitations and special cases

Do not repeatedly submit a job that is still running. Partial success requires reviewing failed items, not reversing successful ones.
