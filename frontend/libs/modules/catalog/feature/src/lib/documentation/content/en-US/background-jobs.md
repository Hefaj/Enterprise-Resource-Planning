# Background jobs

The tasks panel shows progress and results for operations that do not finish immediately.

## Who can perform the operation

A job is visible to the user who started the operation and can access the module.

## Where to find the feature

Use the tasks button in the application header after starting a bulk operation or derivative generation.

## How to perform the operation

Open the panel, find the job by type and start time, then review success and error counts. If the job produced a file, use the result download action.

## Result

Status changes in real time. A completed run retains its summary and, where applicable, a link to its artifact.

## Limitations and special cases

One failed item does not necessarily fail the whole job. File links can expire and are generated again when requested.

## Related topics

Jobs are created by [Bulk editing](doc:catalog.products.bulk-edit) and the [Media library](doc:catalog.multimedia.library), among other features.
