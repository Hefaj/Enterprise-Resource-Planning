# Konfiguracja projektu

Karta projektu zarządza kodem, archiwizacją, polami, typami, workflow i ustawieniami projektu.

## Kto może wykonać operację

Wymagane jest uprawnienie zarządzania projektem; konfiguracja schematów może wymagać dodatkowego uprawnienia.

## Gdzie znaleźć funkcję

Otwórz projekt z listy Projektów.

## Jak wykonać operację

Wybierz właściwą zakładkę, zmień ustawienie i zatwierdź. Przed archiwizacją sprawdź ostrzeżenie. Pole niestandardowe dodawaj z typem i trwałym przypisaniem slotu.

## Rezultat

Nowa konfiguracja staje się źródłem kolumn, filtrów, formularzy i dozwolonych przejść dla projektu.

## Ograniczenia i przypadki szczególne

Nie można bezpiecznie usunąć pola mającego wartości. Zmiana kodu projektu wpływa na nowe klucze zgłoszeń, ale nie może unieważnić starych linków.
