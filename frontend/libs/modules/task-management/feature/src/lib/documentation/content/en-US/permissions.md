# Work management permissions

Global permissions combine with project membership and role to determine visible data and available actions.

## Who can perform the operation

Every module user can read this guide; an Identity administrator changes global grants.

## Where to find the feature

Access is reflected by visible screens and actions. Identity manages grants, while the project page manages membership.

## How to perform the operation

For a missing feature, check the relevant permission: read, create, update, bulk operation, project, board or scheme management, or cross-project report access.

## Result

With a valid grant, menu items and actions are available while the backend independently enforces the same contract.

## Limitations and special cases

A project role does not replace a global permission. A missing button does not necessarily indicate a UI defect.
