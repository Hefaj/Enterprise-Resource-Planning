# Product catalog

The catalog is used to find products, perform bulk changes, and manage product files.

## Who can perform the operation

The module is available to users who can read products. Individual actions can require additional permissions described under [Permissions](doc:catalog.permissions).

## Where to find the feature

Open Catalog from the main menu. The product list and Media library are separate screens.

## How to perform the operation

Choose a topic in the documentation navigation, then open the corresponding module screen.

## Result

Direct changes appear on the screen, while bulk operations can be tracked in the tasks panel.

## Limitations and special cases

Menu placeholders without a working screen are not part of the documented Catalog capabilities.
