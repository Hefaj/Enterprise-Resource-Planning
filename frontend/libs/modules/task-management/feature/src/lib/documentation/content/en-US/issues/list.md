# Issue list

The list searches, filters, and runs actions on issues without loading the complete result set.

## Who can perform the operation

Reading requires issue access; creation and bulk actions have separate permissions.

## Where to find the feature

Choose Issues in Work management.

## How to perform the operation

Select a scope and project, set filters, and apply them. Open an issue by its key. Select rows to use the available bulk actions.

## Result

The table shows a server-side page with columns derived from the project's field profile.

## Limitations and special cases

“Select all” covers the complete current filter, not only the visible page. A bulk job can report errors for individual items.
