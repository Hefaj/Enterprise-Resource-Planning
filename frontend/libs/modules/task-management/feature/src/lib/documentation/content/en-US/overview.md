# Work management

The module brings projects, issues, boards, requests, and reports into one team workspace.

## Who can perform the operation

Module access requires issue read permission. Individual changes may require additional permissions.

## Where to find the feature

Choose Work management in the main menu, then open the required screen.

## How to perform the operation

Start with the issue or project list. Open boards, requests, and reports from the module menu.

## Result

You see only projects and issues included in your access scope.

## Limitations and special cases

A missing item or action usually means that permission is missing or the feature is unavailable for that project.
