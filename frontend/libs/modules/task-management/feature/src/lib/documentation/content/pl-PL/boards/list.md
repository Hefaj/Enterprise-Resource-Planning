# Lista tablic

Lista tablic prowadzi do widoków pracy dostępnych w Twoich projektach.

## Kto może wykonać operację

Wymagane jest uprawnienie odczytu zgłoszeń i widoczność projektu tablicy.

## Gdzie znaleźć funkcję

W module Zarządzanie pracą wybierz Tablica.

## Jak wykonać operację

Wybierz tablicę z listy. Jeśli dostępna jest tylko jedna, ekran może od razu otworzyć jej widok.

## Rezultat

Otwiera się tablica z kolumnami wynikającymi z workflow projektu.

## Ograniczenia i przypadki szczególne

Tablica nie pokazuje zgłoszeń poza Twoim zakresem. Jej adres używa UUID tablicy.
