# Cross-department requests

The request view gathers work transferred between a requesting and a delivery department.

## Who can perform the operation

Issue read permission and visibility of the relevant Intake projects are required.

## Where to find the feature

Choose Requests in Work management.

## How to perform the operation

Select a scope and intake project, apply filters, then open a request to inspect linked delivery work and delivery state.

## Result

The list shows accessible requests with progress derived from linked delivery work.

## Limitations and special cases

A link does not grant access to hidden issue content. Acceptance of a delivered result remains an explicit human decision.
