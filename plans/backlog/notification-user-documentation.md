# Notification — dokumentacja użytkownika

> **Status:** backlog
> **Warunek rozpoczęcia:** audyt panelu zadań, skrzynki powiadomień i pobierania artefaktów.

## Zakres

1. Oddzielić instrukcje panelu zadań od instrukcji osobistych powiadomień.
2. Zweryfikować postęp realtime, błędy częściowe, ponowienie i pobieranie rezultatu.
3. Utworzyć artykuły PL/EN, manifest, indeksy i lekki kontrakt remota.
4. Dodać pomoc kontekstową do samodzielnych ekranów Notification; widżety shellu powiązać z
   odpowiednim artykułem przez stabilny identyfikator.
5. Zweryfikować częściową awarię remota w globalnym `/help`.
