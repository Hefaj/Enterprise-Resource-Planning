# Board list

The board list opens work views available in your projects.

## Who can perform the operation

Issue read permission and visibility of the board's project are required.

## Where to find the feature

Choose Board in Work management.

## How to perform the operation

Select a board. When only one is available, the screen may open it immediately.

## Result

The board opens with columns derived from the project workflow.

## Limitations and special cases

The board does not show issues outside your scope. Its address uses the board UUID.
