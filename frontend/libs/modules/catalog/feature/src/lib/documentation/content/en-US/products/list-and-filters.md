# Product list and filters

The product list narrows a large catalog while preserving the context of the selected record.

## Who can perform the operation

Product read permission is required.

## Where to find the feature

Open the products screen in Catalog. Filters are displayed next to the table.

## How to perform the operation

Enter the required criteria, apply the filter, then use table sorting or pagination. Select a row to open product-specific information.

## Result

The table displays a server-side page matching the criteria, while the count and selection apply to the complete result set.

## Limitations and special cases

“Select all” means every result of the current filter, not only the visible page.

## Related topics

Selected products can be changed with [Bulk editing](doc:catalog.products.bulk-edit).
